Muse Wonder is Meta Superintelligence Labs' current frontier family, released October 12, 2026 in two versions — Muse Wonder and the more capable Muse Wonder Full — superseding the earlier lightweight Muse Spark 1.3 (September 2, 2026) as the company's flagship. The API-accessible Wonder model runs on the Meta Model API at $4 per million input tokens and $20 per million output tokens, roughly in line with Claude Opus 5.5, while Wonder Full is reserved for Muse Code subscribers and has no public API. With a context window of around one million tokens, the Wonder models target personal and professional agentic work, including coding and complex multi-step tasks.
