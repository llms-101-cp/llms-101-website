Muse Spark is the first model family from Meta Superintelligence Labs, introduced in April 2026 and first versioned as Muse Spark 1.1 on July 9, 2026, followed by Muse Spark 1.2 (August 5, 2026) and the current flagship, Muse Spark 1.3 (September 2, 2026). Muse Spark 1.3 is a natively multimodal reasoning model aimed at agentic workflows and coding, with a 1,048,576-token (~1M) context window and roughly 20% fewer tool calls and 25% fewer tokens than 1.2. It is proprietary and closed-weight, available through the Meta Model API and the Muse Code agent, with standard API pricing around $1.25 per million input tokens and $4.25 per million output tokens.
