Muse Spark is Meta Superintelligence Labs' large language model family, which debuted in April 2026 and now runs on Muse Spark 1.2, released August 5, 2026, alongside the Muse Code terminal coding agent. The coding-focused 1.2 model succeeds Muse Spark 1.1 (July 9, 2026) and the original Muse Spark, and offers a 1-million-token (1,048,576) context window with standard API pricing of $1.25 per million input tokens. It's built primarily for repository-scale software engineering — planning changes, writing code, and validating results across large codebases.
