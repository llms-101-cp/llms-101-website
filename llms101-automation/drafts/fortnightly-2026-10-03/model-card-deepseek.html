As of October 3, 2026, DeepSeek's current lineup is led by DeepSeek-V4.1-Flash, a 552B-parameter Mixture-of-Experts model with native image-and-text (multimodal) input and a 1-million-token context window, released September 10, 2026 under an MIT open-weights license and served via the DeepSeek API as "deepseek-flash." It replaced the retired original V4-Flash, whose legacy name now routes to V4.1-Flash. The older V4 Pro flagship is in flux: DeepSeek announced that from 04:00 UTC on September 14, 2026 all deepseek-v4-pro requests would route to V4.1-Flash at Flash prices until an unreleased V4.1-Pro ships, though it later indicated it may keep V4 Pro service running — so confirm current status directly with DeepSeek before relying on either model name.
